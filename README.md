# Telegram Chess Bot - Static Files

## Описание
Это архив содержит все необходимые статические файлы для веб-приложения Telegram Chess Bot.

## Структура файлов:
- index.html - главная страница веб-приложения
- static/css/style.css - стили в фиолетово-лиловой цветовой схеме
- static/js/app.js - основная логика приложения
- static/js/stockfish.js - упрощенный шахматный движок
- static/img/ - иконки и изображения

## Установка:
1. Распакуйте архив в корневую папку вашего веб-сервера
2. Убедитесь, что index.html доступен по HTTPS
3. Настройте веб-сервер для обслуживания статических файлов
4. Добавьте URL в BotFather для Telegram Mini App

## Требования:
- HTTPS протокол (обязательно для Telegram WebApp)
- Поддержка статических файлов на веб-сервере
- Современный браузер с поддержкой ES6

## Настройка для GitHub Pages:
1. Создайте репозиторий на GitHub
2. Загрузите все файлы в корень репозитория
3. Включите GitHub Pages в настройках
4. Используйте URL: https://username.github.io/repository-name/

## Настройка для других платформ:
- Netlify: перетащите папку в веб-интерфейс
- Vercel: подключите GitHub репозиторий
- Amvera: используйте Git deploy

## Кастомизация:
- Замените static/img/logo.png на ваш логотип
- Обновите цветовую схему в static/css/style.css
- Добавьте дополнительные иконки в static/img/
